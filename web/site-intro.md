## Try Java in your browser

[Open the Java playground](https://theseus-rs.github.io/ristretto/playground/) to write, compile, and run Java with Ristretto. Your code stays on your device, and no installation is needed.

[Open JShell](https://theseus-rs.github.io/ristretto/jshell/) to evaluate expressions, define variables and methods, and experiment with Java in a persistent, interactive shell. Switch between both pages with the dropdown beside the Ristretto name.
