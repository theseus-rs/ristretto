Try JVM languages in your browser

Open the playground to run Java, Kotlin, Groovy, Scala 2 and 3, and Clojure with Ristretto. Choose a language, start from an example, and run your code. Your code stays on your device, and no installation is needed.

Open JShell to evaluate expressions, define variables and methods, and experiment with Java in a persistent, interactive shell. Switch between both pages with the dropdown beside the Ristretto name.
